Privacy Policy

shorts-otomatis · Last updated: October 16, 2026 (rev. 2)

What this app is

shorts-otomatis is a private, single-user tool run by the owner of this website. It publishes short videos produced by the owner to the owner's own YouTube channel and reads that channel's analytics. It is not offered to other users.

YouTube API Services

This app uses YouTube API Services. By using it you agree to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

Google user data the app accesses

  • Upload videos (youtube.upload): to upload and schedule the owner's own videos.
  • Read the channel (youtube.readonly): to confirm uploads and read the status of the owner's own videos.
  • Read channel analytics (yt-analytics.readonly): views, watch time and retention of the owner's own videos.
  • Manage the channel (youtube.force-ssl): update the owner's own channel description, keywords and banner, and change the privacy setting or schedule of the owner's own videos.

How the data is used

The data is used only to publish the owner's videos and to measure how they perform, so the owner can decide what to make next. It is not used for advertising, not sold, not shared with third parties, and not used to train AI models.

The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and security

The OAuth access token and the analytics figures are stored only on the owner's own computer, in files readable only by the owner's account. No YouTube data is stored on any server operated by this app.

Retention and deletion

Data is kept only while the tool is in use. Access can be revoked at any time at Google Account permissions (also reachable at security.google.com/settings/security/permissions). After revocation the locally stored token stops working and the local data is deleted.
